# resolutions

Official decisions adopted by the collective. Contains the resolution texts with date, subject, and decision basis. Stored append-only so the record stays traceable.

## Where the register actually lives

This package is reserved for resolutions that are meant to be **public**. The
working register of all decisions — resolutions of the association's bodies and
technical decision records alike — is kept **internally** in
`aoc-board/packages/decisions`, because there is no legal duty to publish
resolutions and most of them concern internal administration.

Publish a resolution here only when there is a reason to: it affects non-members,
it is referenced by a public document, or the board decides to make it public. In
that case, copy the text here and link back to its `D-<nnn>` entry in the internal
register.
